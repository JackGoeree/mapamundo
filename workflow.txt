1. Download CHELSA data from here: https://envicloud.wsl.ch/#/?bucket=https%3A%2F%2Fos.zhdk.cloud.switch.ch%2Fchelsav2%2F&prefix=%2F
- global/monthly/tas
- global/monthly/hurs

2. Drag the TIF files into QGIS.

3. QGIS: Raster calculator to convert tas from tenth kelvin to celsius:
("tas11@1" / 10) - 273.15

4. QGIS Raster calculator to get the comfort index: 
( "tas11c@1" < 20 ) * "tas11c@1" +
( "tas11c@1" >= 20 ) * (
  "tas11c@1" + 
  ( ( "hurs11@1" / 100 ) ^ 2 ) * 
  ( "tas11c@1" - 20 ) * 6
)

Note: REMEMBER THE @1 AFTER LAYER NAMES

5. QGIS: Raster → Extraction → Clip Raster by Mask Layer to remove water. Check keep resolution of input raster. Save the output to a file. Use this as mask: https://www.naturalearthdata.com/http//www.naturalearthdata.com/download/10m/physical/ne_10m_land.zip

6. QGIS: double click the comfort layer > Symbology > Render type change to Singleband pseudocolor. Pick color ramp turbo. Set min to -15 and max to 50.

7. QGIS: In bottom right, change to EPSG:3857.

8. QGIS: Processing toolbox: Generate XYZ tiles (zoom 1-7).

9. Drop tile folders into mapamundo folder.

Note: any errors at step 8 usually caused by incorrect EPSG. Try warp (reproject) to EPSG 3857
